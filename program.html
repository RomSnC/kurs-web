Головна Програма Контакти

Програма курсу

5 модулів і 23 заняття: від роботи з текстом до власного сайту й перевіреного застосунку.

Записатися

Модуль 1. Робота з текстом

  1. Заняття 1. Просунутий prompting та SkillsСтруктуровані запити з тегами, ітеративне уточнення й перший власний skill.
  2. Заняття 2. Projects та поглиблене створення skillПроєкти з базою знань та skill як повний робочий процес.
  3. Заняття 3. Artifacts і робота з файламиДокумент-артефакт, версії та редагування готових Word і PDF файлів.
  4. Заняття 4. Cowork для текстових завданьПоняття агента й повний цикл від збору матеріалу до фінальної версії.

Модуль 2. Аналітика даних

  1. Заняття 5. Основи роботи з даними та візуалізаціяОчищення таблиць, обчислення й звіт із графіками.
  2. Заняття 6. Claude for ExcelПитання до книги з посиланнями на клітинки й пошук помилок у формулах.
  3. Заняття 7. Projects і Skills для аналітикиПроєкт для регулярної звітності та skill зі структурою звіту.
  4. Заняття 8. Cowork для комплексних аналітичних задачЗведений звіт із кількох джерел і завдання за розкладом.

Модуль 3. Claude Design

  1. Заняття 9. Технічне завдання та вступ до Claude DesignСкладання ТЗ через інтерв'ю з Claude і перші прототипи.
  2. Заняття 10. Дизайн-система і макетиКольори, шрифти, кнопки та макет головної сторінки.
  3. Заняття 11. Шрифти, доступність і читабельністьКонтраст, розміри, підписи й кирилиця в шрифтах.
  4. Заняття 12. Практичний кейс: комплексний дизайн-проєктПовний цикл від ТЗ до перевіреного макета.

Модуль 4. Створення сайту з Claude Code

  1. Заняття 13. Вступ до Claude Code та поняття агентаАгент, що діє, режими роботи й хендоф між сесіями.
  2. Заняття 14. Безпека агентівПоверхня атаки, prompt injection і правило мінімальних доступів.
  3. Заняття 15. Промпти для агентів та економія контекстуПерсона плюс знання, перевірні критерії й робота з контекстом.
  4. Заняття 16. Git, термінал і GitHub — основиІсторія змін, коміти, гілки, dev-сервер і сховище на GitHub.
  5. Заняття 17. Контент і публікація матеріалівDeep Research, контент-план і розмітка Markdown.
  6. Заняття 18. Хостинг, домен і деплойДомен, DNS, розміщення сайту на сервері й розсилки.
  7. Заняття 19. Субагенти і Skills у Claude CodeКонфігурація субагента й затвердження перед використанням.
  8. Заняття 20. Claude Code, Codex і Manus: кросплатформене рев'юОдне ТЗ для трьох агентів і незалежна перевірка результату.

Модуль 5. Manus: від вимог до перевіреного застосунку

  1. Заняття 21. Спільне ТЗ та порівняння результатівПорівняння агентних середовищ за однаковим брифом і тестами.
  2. Заняття 22. Manus Project і прототип застосункуВимоги, ролі й прототип у Preview на синтетичних даних.
  3. Заняття 23. Тестування, рев'ю та передавання застосункуТест-кейси, баг-репорти, регресія й план передавання.
