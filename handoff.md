# Хендоф: сайт курсу

Оновлено наприкінці заняття 15.

## Мета
Сайт «Просунутий курс з AI»: відвідувач дізнається про курс і записується на нього.

## Що зроблено
- index.html — головна сторінка: hero, «Чого ви навчитеся» (5 модулів), «Коротко про курс», футер із контактами.
- program.html — програма курсу: 5 модулів, 23 заняття з коротким описом, кнопка «Записатися».
- style.css — спільні стилі (дизайн-система «Сайт курсу, музей»).
- CLAUDE.md — постійні правила проєкту, зокрема правила безпеки.
- plan.md — план робіт.
- .gitignore — git не відстежує службові файли системи й редакторів, тимчасові файли Word, особисті налаштування Claude Code і файли з секретами.

## Прийняті рішення
- Дата старту курсу — 1 листопада 2026 (уточнено 24.10.2026, внесено в index.html).
- Основний текст — 18 пікселів, шрифти Noto Sans і Noto Serif (повна підтримка української кирилиці).
- Кольори: теплий коричневий для заголовків, теракотовий для кнопок, світлий теплий фон.
- Назви занять беремо лише з програми курсу, нічого не вигадуємо.

## Відкриті питання
- Формат занять (онлайн чи в музеї), контакти — позначено в квадратних дужках.
- Як саме записуватися на курс: форма на сайті, пошта чи телефон?
- Фото для головної сторінки (зараз плейсхолдер).
